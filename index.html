Android setup (do this once)
  1. Open this page in Chrome, tap ⋮ → Install app (or Add to Home screen), then open it from the home-screen icon.
  2. Allow Location and Notifications when asked.
  3. Phone Settings → Apps → Chrome (or Alight Alert) → Battery → Unrestricted. Turn off Battery Saver for the ride.
  4. For the on-screen pop-up banner and vibration in other apps: Phone Settings → Apps → Alight Alert (or Chrome) → Notifications → open the Alight Alert / site category → set importance to Urgent / Pop on screen and keep Vibration on. Turn off Do Not Disturb.
  5. The alarm plays on media volume, not ringer volume. Turn media volume up.
  6. Tap Test alarm before every trip. Don't swipe the app away while riding.
How it works / limits
  • A near-silent sound plays while tracking so Android treats the page like a music player and is less likely to freeze it. This is best effort, not guaranteed.
  • Some phones stop sending location when the screen is off. Black screen mode keeps the screen technically on but black, which is the safest option.
  • Underground, GPS is lost. The app then estimates your position (marked ~) and the backup timer is your safety net.
  • A web page can only vibrate the phone while it is on screen. In other apps, the alarm re-posts its notification every 5 seconds so Android vibrates the phone itself. This needs the notification setting above.
  • Bus stops: the list of Singapore bus stops downloads the first time you use Bus mode, then is saved on your phone.
